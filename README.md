# Signing Off

A small, self-contained "signing off" farewell page — a single `index.html` with no dependencies, ready to host on GitHub Pages.

## Preview locally

Just open `index.html` in a browser.

## Host on GitHub Pages

1. Push this repo to GitHub.
2. In the repo, go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to `Deploy from a branch`, branch `main` (or `master`), folder `/ (root)`.
4. Save — GitHub will publish the page at `https://<username>.github.io/<repo-name>/`.

## Customize

Edit the contact links near the bottom of `index.html` (email, LinkedIn, GitHub) before publishing.
